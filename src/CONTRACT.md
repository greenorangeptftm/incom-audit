# Контракт страниц полного сайта («Печать», SEO-версия)

Генератор: `full-src/build.py` (Python 3, без зависимостей) читает модули из `full-src/pages/*.py`
и пишет готовый статический сайт в `site/full/` (на GitHub Pages это `/incom-redesign/full/`).

## Модуль страницы

Каждый файл `full-src/pages/<имя>.py` экспортирует словарь `PAGE`:

```python
PAGE = dict(
  kind="service",          # "home" | "hub" | "service" | "page" | "article" | "blog" | "contacts" | "order"
  path="audit/obyazatelnyj/",   # папка относительно корня сайта; главная = ""
  title="Обязательный аудит: кому нужен, сроки и стоимость | Инком-Аудит",  # ≤ 70 знаков
  description="...",       # meta description, 120–160 знаков, с ключевой фразой
  h1="Обязательный аудит бухгалтерской отчётности",
  kicker="Аудит · по всей России",        # короткая строка над h1 (необязательно)
  lead="1–2 предложения под h1.",
  photo="signing-hands",   # ключ фотографии для первого экрана (см. список ниже), необязательно
  cta=("Рассчитать стоимость", "#zayavka"),            # основная кнопка
  cta2=("Нужен ли нам аудит?", "/audit/obyazatelnyj/#check"),  # вторая кнопка, необязательно
  facts=[("Стоимость", "от 40 000 ₽"), ("Результат", "заключение + письменная информация"), ...],  # 3–4 пары в полосу под первым экраном
  breadcrumbs=[("Главная", "/"), ("Аудит", "/audit/"), ("Обязательный аудит", None)],  # последний без ссылки
  sections=[ ... ],        # список секций, см. типы ниже
  faq=[("Вопрос?", "Ответ в 1–3 предложения."), ...],   # рендерится как аккордеон + FAQPage JSON-LD
  # related=[...] — блок «Смотрите также» убран со всего сайта 29.10.2026 по просьбе клиента, ключ больше не задавать
  schema=dict(service="Обязательный аудит бухгалтерской отчётности"),   # для kind="service": Service JSON-LD
  # только для kind="article":
  date="2026-10-20", updated="2026-10-20", author="Аудиторы «Инком-Аудит»", reading="6 мин", tags=["обязательный аудит"],
  excerpt="1–2 предложения для карточки в блоге.",
)
```

## Ссылки и фото

- Внутренние ссылки пишутся от корня сайта: `href="/audit/obyazatelnyj/"`, `"/blog/"`, `"/#zayavka"`.
  Сборщик сам переводит их в относительные (на GitHub Pages сайт живёт в подпапке).
- Фотографии только по ключу: в секциях `photo="ключ"`, в HTML-тексте `<img data-photo="ключ" alt="…">`.
  Ключи: `moscow-city-sunset`, `moscow-city-park`, `moscow-city-golden`, `moscow-city-aerial`,
  `moscow-stalin-highrise` (портрет), `signing-hands`, `signing-pen`, `paper-stack`, `binders-color`,
  `binders-archive`, `card-cabinet`, `seal-dark` (портрет), `ind-trade` (портрет), `ind-construction`,
  `ind-construction-2` (портрет), `ind-production`, `ind-production-2`, `ind-leasing`, `ind-it`.
  Все фото рендерятся чернильным дуотоном, как в варианте «Печать».
- Форма заявки есть на каждой странице внизу (`#zayavka`), отдельно её вставлять не нужно.

## Типы секций (`sections`)

Каждая секция — словарь с ключом `type`. У любой секции может быть `id` (якорь) и `h2`.

| type | поля | что это |
|---|---|---|
| `prose` | `h2`, `html` | основной текст: `<p>`, `<ul>`, `<ol>`, `<h3>`, `<table>`, `<blockquote>`; 1 секция = 1 тема |
| `facts` | `h2`, `items=[(label, value), ...]` | сетка «реквизитов» (равные ячейки) |
| `steps` | `h2`, `intro`, `items=[(title, text), ...]` | нумерованные этапы (реальная последовательность) |
| `cards` | `h2`, `intro`, `items=[(title, text, href), ...]` | равные карточки-ссылки (услуги, разделы) |
| `table` | `h2`, `intro`, `head=[...]`, `rows=[[...], ...]`, `note` | таблица-бланк (критерии, сроки, факторы цены) |
| `checklist` | `h2`, `intro`, `items=["...", ...]` | список с галочками (документы, что получите) |
| `checker` | `h2`, `intro` | интерактивная проверка «нужен ли обязательный аудит» (компонент) |
| `calculator` | `h2`, `intro` | форма-оценка стоимости (компонент; результат — «от 40 000 ₽ + факторы», без выдуманных цифр) |
| `photo` | `photo`, `caption` | полноширинное фото в дуотоне с подписью |
| `quote` | `text`, `source` | выделенная цитата из закона/стандарта с точной ссылкой на статью |
| `articles` | `h2`, `limit` | карточки последних статей блога (автоматически) |
| `cta` | `h2`, `text`, `button=(label, href)` | синяя полоса-призыв |

## Правила контента

- Русский, просто и уверенно, «вы» со строчной. Короткие предложения. Без воды и без обещаний
  («гарантируем», «лучшие») и без выдуманных кейсов, людей, отзывов, сроков и цен.
- Факты компании: с 2010 года; 300+ проектов; ООО «Инком-Аудит»; член СРО ААС «Содружество»,
  ОРНЗ 12006082980; аудит от 40 000 ₽ (другие услуги — «после оценки объёма»); +7 (499) 130-80-18;
  help@incom-consult.ru; офис в Москве, работаем по всей России (на месте и удалённо).
- Закон: 307-ФЗ «Об аудиторской деятельности» (ст. 5 — обязательный аудит: доходы за предыдущий год
  > 800 млн ₽ или активы на 31 декабря > 400 млн ₽; АО; застройщики по 214-ФЗ; ценные бумаги на торгах,
  консолидированная отчётность и другие случаи по иным законам). Сегодня октябрь 2026: ближайший аудит —
  отчётность за 2026 год, проверка в 2027-м по показателям 2025 года (доходы) и на 31.12.2025 (активы).
  Всё, в чём нет уверенности (штрафы, сроки сдачи), формулировать осторожно и с отсылкой к норме; лучше
  меньше цифр, чем одна неверная.
- Ключевые фразы вставлять естественно: в h1, title, description, первый абзац, 1–2 h2. Без спама.
- Объём: страница услуги 900–1600 слов, хаб 500–900, статья 1000–1800. Каждый абзац отвечает на вопрос
  главбуха или собственника.
