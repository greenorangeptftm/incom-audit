# Выкладка на домен: чек-лист

Сайт статический, собирается `src/build.py`, публикуется из папки `docs/` через GitHub Pages.
Предрелизный аудит (30.10.2026) пройден: валидный HTML, ссылки и картинки без ошибок, консоль чистая,
Lighthouse на телефоне 84–97, на компьютере 97. Ниже то, что делается руками в день выкладки.

## 1. Сборка под боевой домен
```
python3 src/build.py --theme sverka --out docs --site-url https://ДОМЕН --index
```
`--index` убирает `noindex` со страниц и пишет открытый `robots.txt`. Все canonical, og:url, sitemap и JSON-LD
берут адрес из `--site-url`. Страницы `/info/` и `/policy/` закрыты от поиска по просьбе клиента и в sitemap не входят.

## 2. Домен
- Файл `CNAME` с доменом положить в `src/assets-sverka/_root/` (оттуда он копируется в корень `docs/` при каждой сборке;
  класть прямо в `docs/` нельзя, сборка чистит папку).
- DNS: A-записи GitHub Pages (185.199.108.153, .109.153, .110.153, .111.153) для корневого домена и CNAME `www` → `greenorangeptftm.github.io`.
- В настройках репозитория (Pages) указать домен и включить «Enforce HTTPS».
- Старый сайт incom-consult.ru (WordPress): все его адреса из sitemap уже ведут на новые страницы заглушками
  с мгновенной переадресацией (`redirect_from` в `src/pages/*.py`, 68 адресов). Если домен будет другой,
  на старом хостинге нужны серверные 301 на новый домен.

## 3. Форма заявки
Сейчас форма только проверяет поля и показывает сообщение, что это тестовая версия. Перед выкладкой нужен
получатель заявок (почта, Telegram-бот или сервис форм) и правка `sverka.js` под него. Без этого выкладывать нельзя.

## 4. Поисковики и аналитика
- Яндекс.Вебмастер и Google Search Console: подтвердить сайт, отправить `https://ДОМЕН/sitemap.xml`.
  Место для `<meta name="yandex-verification">` помечено комментарием в `<head>` (шаблон `base()` в `src/templates_sverka.py`).
- Яндекс.Метрика: код счетчика вставить перед `</head>` там же. Если добавляется счетчик, политика обработки данных
  должна упоминать cookies и Метрику.

## 5. Тексты (решает клиент)
- Заголовки длиннее 60 знаков (режутся в выдаче): дью дилидженс, инициативный аудит, две статьи блога, консалтинг, контакты.
- Описания длиннее 160 знаков: контакты, о компании, раскрытие информации.
- Раскрытие информации за 2025 год, юридическая проверка политики.

## 6. Повторная проверка после сборки
```
python3 src/tools/site_audit.py docs https://ДОМЕН --external
```
Проверяет мета-теги, canonical, Open Graph, JSON-LD, заголовки, все внутренние ссылки и якоря, картинки, sitemap и robots.
