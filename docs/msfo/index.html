Подготовка финансовой отчетности по МСФО

Как правило, пользователями финансовой отчетности, подготовленной в соответствии с требованиями МСФО, являются финансовые институты, инвесторы, а также иностранные собственники. Такая отчетность дает ряд преимуществ для компаний, в том числе расширение клиентской базы и возможность привлечения дополнительных инвестиций

Когда компании нужна отчетность по МСФО

  • Для предоставления в банк: при рассмотрении заявки на кредитование
  • Для инвестора (покупателя доли): перед принятием решения о покупке
  • Для иностранных партнеров или собственников: для консолидации на уровне группы, управленческих целей и т.п.
  • Законодательство обязывает группу компаний готовить консолидированную отчетность по МСФО

Форматы подготовки отчетности

Подготовка финансовой отчетности по МСФО

Готовим финансовую отчетность в соответствии с требованиями МСФО путем трансформации данных российского бухгалтерского учета компании: разработка учетной политики по МСФО, расчет корректировок, подготовка раскрытий, перевод на английский язык (при необходимости)

Подготовка консолидированной отчетности группы

Готовим консолидированную отчетность группы компаний: определение периметра консолидации, исключение внутригрупповых остатков и оборотов, определение чистой стоимости инвестиций в дочерние и ассоциированные компании, оценка гудвила и доли неконтролирующих участников

Что вы получаете

  • Комплект индивидуальной финансовой отчетности, составленной по стандартам МСФО, либо консолидированную отчетность, включая пояснения
  • Рабочие файлы с трансформационными или консолидационными таблицами в Excel
  • Расчет всех корректировок в Excel

Часто задаваемые вопросы

Сколько стоит подготовка отчетности по МСФО?

Цена услуги зависит от многих факторов, в том числе: от требований пользователей отчетности, качества российского учета, состава статей, количества компаний группы

Нужно ли вести параллельный учет по МСФО?

Если компания готовит отчетность по стандартам МСФО раз в год, либо по запросу банка, вести параллельный учет по МСФО нет необходимости, достаточно выполнить трансформацию на отчетную дату. Если компания готовит МСФО отчетность на ежеквартальной или ежемесячной основе, может быть целесообразно вести параллельный учет

Примет ли банк отчетность по МСФО без аудиторского заключения?

В зависимости от банка и суммы кредита. На первом этапе рассмотрения банку может быть достаточно неаудированной отчетности
